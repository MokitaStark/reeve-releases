# Reeve

Reeve 的公开安装包与签名自动更新发布仓库。应用源码保留在独立的私有仓库。

**首次可安装版本仍在开发，目前尚未发布安装包。** 可用版本将在 [Releases](https://github.com/chengyunyi/reeve-releases/releases) 中提供。

## 发布约定

- 桌面版本标签：`desktop-v<版本>`，例如 `desktop-v0.1.0-beta.1`。
- 测试版本标记为 prerelease，稳定客户端不会自动安装测试版本。
- 更新清单：`update-<系统>-<架构>.json`；安装档案和差分更新由 Ed25519 签名。
- `update.pub` 是公开验签公钥，签名私钥不存放在本仓库。
- 本仓库仅存放发布说明、安装包及更新元数据，不存放应用源码、个人项目数据或模型凭据。

当前建立的是发布通道；完整安装与自动更新验收将在首个桌面版本完成后进行。
